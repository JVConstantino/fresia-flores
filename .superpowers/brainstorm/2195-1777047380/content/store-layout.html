Página de Loja — qual layout prefere?

O protótipo tem sidebar com filtros. Mostre se prefere manter ou simplificar.

A

Sidebar + grid (protótipo)

Filtros laterais sticky (categoria, preço). Grid de 4 colunas à direita. Mais poderoso para loja grande.

B

Chips de categoria + grid (sem sidebar)

Barra de chips horizontais para filtrar por categoria. Grid de 3 colunas full-width. Mais limpo e simples.
