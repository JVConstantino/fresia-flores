## Decisões técnicas

| Decisão | Escolha | Motivo |
|---------|---------|--------|
| Banco | MariaDB XAMPP (sem Docker) | Docker Desktop falhou na instalação (requer virtualização) |
| Python | 3.11 (instalado via winget) | lightrag-hku requer 3.10+ |
| Node | v24.14 | já disponível |
| qmd | @tobilu/qmd 2.1.0 | o pacote `qmd` no npm é placeholder |
| darkMode | `class` no Tailwind | desativa ativação pelo sistema operacional |
| Checkout auth | Login obrigatório antes | `neighborhoodId` exige usuário para criar Order |
| Admin auth | isAdmin = true no seed | sem UI de gerenciamento de usuários por ora |
