    - Migrado de `axios` direto para `adminStatsService` (com credenciais)

## Decisões tomadas

- **adminMiddleware duplicado**: removido dos controllers que já recebem via `server.ts`. Simplifica e evita confusão.
- **Formato de resposta inconsistente**: frontend ajustado para aceitar tanto array direto quanto `{data}` wrapper — flexibilidade para evitar quebra.
- **Category.createdAt**: campo não existe no schema Prisma. Substituído por `_count.products` na tabela.
- **useStats**: migrado para usar o service com `withCredentials` em vez de axios "naked" sem cookies.
